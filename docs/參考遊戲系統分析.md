# Endless Puncher 系統分析（設計參考用）

來源：使用者提供的 APK 中 `global-metadata.dat`（Unity 6 / IL2CPP，未加密）。
只擷取類別、欄位、列舉的**名稱**來理解系統架構；不含任何美術、音效、文字素材，也不複製其內容。

## 技術
- 引擎：Unity 6，IL2CPP，3D（Cinemachine 鏡頭、布娃娃 Ragdoll、BossCam）。

## 核心戰鬥
- 出拳：`PunchRange`（出拳距離）、`PunchCount`、出拳速度、`TryHitEnemy`、`LookClotestEnemy`（自動面向最近敵人）。
- 連擊表：`ComboMeter`，會隨時間流失（`ComboMetersDrainRate`），擊殺推進階段（`ComboMeterKillSteps`），倍率 `GetCurrentComboMultiplier`。
  - 相關被動：連擊 x3 獲得護盾、連擊 x5 提升出拳速度、連擊額外傷害、減緩流失。
- 玩家數值（PlayerStatType）：暴擊率、暴擊傷害、最大生命、生命回復、吸血、擊退、經驗獲得、技能傷害（另有出拳傷害）。
- 局內經驗與升級：擊殺得經驗 → 升級 → 選擇技能或數值（`SkillsSelection`、`CanOfferPassiveStat`）。
- 死亡後復活：`GetReviveWithHpAfterDeath`。

## 關卡結構
- 章節（Chapter）→ 關卡（Stage）→ 波次（Wave），章節末有 Boss。
- 數值成長：敵人血量/傷害/體型/數量 分別依「每章、每關、每波」成長。
- 生怪間隔逐步縮短（startDelay / decrease / minDelay）。

## 敵人（EnemyType）
| 代號 | 推測行為 |
|---|---|
| Basic | 基本 |
| Fat | 肥大、高血量 |
| Fast | 快速 |
| Explosive | 自爆 |
| RangedHeadbutt | 遠距離衝撞（頭槌） |
| Laser | 雷射遠程 |
| PoisonMushroom | 毒菇，死亡留毒 |
| DamageBuffer | 替其他敵人加傷害/護盾 |
| Gold | 金幣怪，打倒掉錢 |
| Kicker | 踢擊 |
| Boss1~5 | 五種 Boss，按章節輪替 |
- 另有「菁英」、「強力敵人」標記，以及敵人寵物（EnemyPet，會發射投射物）。

## 技能（SkillType，16 種，裝備在技能欄、冷卻後自動施放）
隕石拳、火箭拳、飛彈連拳、手榴彈拳、死亡炸彈拳、虛空拳、飛刀齊射、火焰拳、寒冰拳、閃電拳、彈跳拳、槍拳、跳彈拳、火焰區域、寒冰區域、閃電區域。
- 技能屬性：冷卻、傷害、持續時間、數量；技能卡有稀有度，可抽卡、合成升級。
- 技能欄依章節解鎖。

## 局內強化（ActiveUpgradesType，元素協同）
燃燒/閃電/冰凍持續時間、燃燒爆炸拳、冰碎片、感電跳躍、元素全體傷害、閃電可點燃、冰凍可點燃、
「附近 5 個感電敵人提高暴擊」、「附近 10 個燃燒敵人提高回血」、「附近 10 個冰凍敵人提高…」、燃燒可疊加。
→ 核心是 **火 / 冰 / 雷 三元素** 的 build 組合。

## 局外成長
- 裝備：手套、頭盔、鞋子三欄，稀有度多階，可合成、升級，高稀有度有寶石槽。
- 寶石：多種（天賦寶石、戒指寶石、寵物寶石、商店寶石…），每局有掉落上限。
- 天賦樹：網格狀、可延伸，天賦含各數值與 16 種技能強化。
- 戒指（Ring）：升級數值，每幾星解鎖特殊效果。
- 收藏品（Collectibles）：碎片升星、套裝加成。
- 家園（Room/Hometown）：裝修房間物件，提供數值。
- 寵物：有特性（PetTrait）、裝備欄。
- 聯賽段位：新人 → 業餘 → 新秀 → 挑戰者 → 競爭者 → 冠軍。
- 其他模式：地下城（Dungeon）、巨人（Giant）、存錢豬（Piggy）、沙包打錢（PunchingBag）、活動通行證。
- 體力（Energy）：Boss 通關回饋體力。
