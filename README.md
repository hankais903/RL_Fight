# RL Fight（Roguelike 拳擊）

3D 斜俯視的 Roguelike 割草拳擊遊戲（Three.js）。玩法方向參考 *Endless Puncher*（主角站在場中央、橡皮手臂自動揍飛四面八方湧來的敵人），角色、美術與數值皆為原創。

## 怎麼玩

用瀏覽器打開 `index.html`（不需安裝）。

- 主角站在八角籠中央，**自動出拳**揍範圍（地上黃色圈）內最近的敵人。
- 打倒敵人得到**經驗**，升級時三選一：數值強化、技能、元素組合。
- **連擊表**：連續打倒敵人會累積，停手會流失。段數越高傷害越高；x3 自動護盾、x4 出拳加速、x5 暴擊提升。
- **技能**冷卻時間到就自動施放；**爆發**蓄滿也會自動震飛全場。全程只需要在升級時做選擇。
- 每章 10 波，第 10 波是頭目。通關後可挑戰下一章或帶著金幣撤退。
- 金幣在**道場**購買永久強化。

| 操作 | 鍵盤 | 手機 |
|---|---|---|
| 選升級 | `1` `2` `3`，`R` 重抽 | 點卡片 |
| 暫停 / 靜音 | `P` / `M` | 右上角 ❚❚ |

## 系統

- **敵人 8 種**（全為近戰）：小嘍囉、快腿仔、肉盾、炸彈客、蠻牛（衝撞）、鼓手（替同伴上盾）、毒菇頭（死亡留毒）、錢袋鼠（掉大量金幣）。
- **頭目 3 種**：鐵拳大王（範圍重擊）、暴走牛王（衝撞）、幫派老大（召喚小弟）。
- **技能 11 種**：火箭飛拳、震地拳、天降鐵拳、迴旋拳套、彈射拳、烈焰拳、烈焰陣、寒霜拳、冰霜爆發、雷電拳、雷霆鏈。
- **元素組合 11 種**：火／冰／雷各自強化，以及雷火、霜火、超導等跨元素組合。

## 專案結構

```
index.html            進入點
css/style.css         介面樣式
js/data.js            敵人、強化、技能、元素組合、道場資料（調數值改這裡）
js/game.js            遊戲邏輯、2D 介面、輸入、音效
js/render3d.js        3D 畫面（Three.js）：擂台、角色骨架與動畫、特效
js/mocap.js           動作捕捉動畫資料（由 tools/mocap/extract.py 產生）
tools/mocap/          動作捕捉轉換工具
vendor/three.min.js   Three.js r128（MIT 授權），讓本機離線也能玩
tools/build_demo.py   打包成單一 HTML（試玩版）
docs/                 參考遊戲系統分析
```

## 動作捕捉資料

角色的出拳、踢腿、架式、走路、跑步都是真人動作捕捉，來自 CMU 動作捕捉資料庫（空手道上段突、前踢、迴旋踢、側踢、飛踢、拳擊等），BVH 轉檔由 Bruce Hahne 製作。CMU 聲明此資料可免費用於研究與商業專案。

> The data used in this project was obtained from mocap.cs.cmu.edu.
> The database was created with funding from NSF EIA-0196217.

重新產生動畫資料：

```bash
python3 tools/mocap/extract.py <放 BVH 檔的資料夾>
```

需要的 BVH 檔（從 https://github.com/una-dinosauria/cmu-mocap 的 `data/` 下載）：135_04、135_07、135_09、135_11、14_01、07_01、141_01、90_05。
