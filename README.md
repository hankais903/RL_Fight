# RL Fight（Roguelike 拳擊）

一款以「左右出拳」為核心的 Roguelike 動作小遊戲，玩法方向參考 *Endless Puncher* 這類「無盡揍人」遊戲，但角色、美術與系統皆為原創。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可（不需要安裝任何東西）。

| 操作 | 鍵盤 | 手機 / 滑鼠 |
|---|---|---|
| 左拳 | `←` / `A` / `J` | 點畫面左半邊 |
| 右拳 | `→` / `D` / `L` | 點畫面右半邊 |
| 暫停 | `P` / `Esc` | 右上角 ❚❚ |
| 靜音 | `M` | — |
| 選強化 | `1` `2` `3`，`R` 重抽 | 點卡片 |

## 核心規則

- 敵人從左右兩側走向主角，進入**出拳距離**（地上的黃色虛線）時出拳就能擊中。
- **揮空**會產生硬直並中斷連擊；被敵人碰到會扣血、中斷連擊。
- 連擊越高，擊倒得分越多。
- 每清完一波，從三張**強化卡**中選一張（普通／稀有／史詩）。
- 每 5 波出現 **BOSS「擂台霸主」**，會突然衝刺。
- 死亡後，該局金幣存入**道場**，可購買永久強化。

## 敵人

| 名稱 | 特性 |
|---|---|
| 小混混 | 基本敵人 |
| 飛毛腿 | 速度很快 |
| 盾兵 | 第一拳只會打破盾牌 |
| 投擲手 | 停在遠處丟酒瓶，酒瓶可以被**打回去** |
| 壯漢 | 多血、難擊退 |
| 自爆客 | 碰到你會爆炸；先打倒它，爆炸會炸傷周圍敵人 |
| 擂台霸主 | BOSS，大量血量，會衝刺 |

## 強化一覽

鐵拳、長臂、會心一擊、致命打擊、連打、貫穿拳、吸血拳、震地波、反擊架勢、專注、重拳、鐵布衫、喘口氣、招財拳、狂熱、護身氣、快拳（詳見 `js/data.js`）。

## 專案結構

```
index.html      進入點
css/style.css   介面樣式
js/data.js      敵人、強化、永久強化等資料（調數值改這裡）
js/game.js      遊戲邏輯、繪圖、輸入、音效
```
